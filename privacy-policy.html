4. 위치 정보의 처리

본 앱은 위치 정보를 수집할 수 있습니다.

4.1 위치 정보 수집 목적

  • 학회 장소(Conrad Hotel, Seoul)까지의 경로 안내
  • 주변 숙박 시설, 식당 등 편의 시설 정보 제공
  • 학회 관련 장소 찾기 서비스 제공

4.2 위치 정보 사용 방법

위치 정보는 사용자가 명시적으로 위치 권한을 허용한 경우에만 수집되며, 위의 목적을 위해서만 사용됩니다. 위치 정보는 실시간으로만 사용되며, 별도로 저장되지 않습니다.

4.3 위치 정보 수집 동의 및 철회

위치 정보 수집은 Android의 런타임 권한 시스템을 통해 사용자의 명시적 동의를 받습니다. 사용자는 기기 설정에서 언제든지 위치 권한을 철회할 수 있으며, 권한을 철회해도 앱의 기본 기능(학회 일정 확인 등)은 계속 이용할 수 있습니다.

5. 개인정보의 보유 및 이용 기간

본 앱은 법령에 따른 개인정보 보유·이용기간 또는 정보주체로부터 개인정보를 수집 시에 동의받은 개인정보 보유·이용기간 내에서 개인정보를 처리·보유합니다.

  • 위치 정보: 실시간 사용만 하며 별도로 저장하지 않습니다.
  • 기기 정보 및 사용 패턴 데이터: 앱 삭제 시까지 또는 계정 삭제 요청 시 즉시 삭제합니다.
  • 계정 정보: 계정 삭제 요청 시 즉시 삭제합니다. 단, 관련 법령에 따라 일정 기간 보관이 필요한 경우 해당 기간 동안 보관 후 삭제합니다.

※ 학회 종료 후 1년이 경과하면 모든 개인정보를 자동으로 삭제합니다.

6. 개인정보의 제3자 제공

본 앱은 원칙적으로 정보주체의 개인정보를 제3자에게 제공하지 않습니다. 다만, 다음의 경우에는 예외로 합니다:

  • 정보주체가 사전에 동의한 경우
  • 법령의 규정에 의거하거나, 수사 목적으로 법령에 정해진 절차와 방법에 따라 수사기관의 요구가 있는 경우

7. 개인정보 처리의 위탁

본 앱은 원칙적으로 개인정보 처리 업무를 외부에 위탁하지 않습니다. 향후 위탁이 필요한 경우, 관련 법령에 따라 위탁 계약 시 개인정보가 안전하게 관리될 수 있도록 필요한 사항을 규정하고, 수탁자에 대한 관리·감독을 실시하겠습니다.

2. Personal Information Collected and Collection Methods

2.1 Personal Information Collected

This app collects the following personal information:

  • Location Information: Device location information may be collected to provide venue guidance and map services. Location information is only collected when the user explicitly consents.
  • Device Information: Device identifiers, operating system version, device model, and other information may be automatically collected to provide app functionality and ensure service stability.
  • Usage Pattern Data: Anonymized usage pattern data such as app usage statistics and feature usage frequency may be collected to improve the service.
  • Account Information (Optional): When creating an account within the app, information such as email address and name may be collected.

2.2 Collection Methods

  • Automatic collection upon app installation and execution (device information, usage pattern data)
  • Location information collection with user consent (when location permission is requested)
  • Information directly entered by users (when creating an account)

3. Purpose of Processing Personal Information

This app processes collected personal information for the following purposes:

  • Providing Conference Schedule and Program Information: Provides information about KCR 2026 conference schedule, presentation programs, abstracts, etc.
  • Providing Location-Based Services: Uses location information to provide venue guidance (Conrad Hotel, Seoul), map services, and information about nearby facilities.
  • Providing App Functionality and Improvements: Utilizes device information and usage pattern data to ensure stable app operation and improve user experience.
  • Maintaining Service Stability: Processes necessary information to resolve technical issues and improve service quality.

4. Processing of Location Information

This app may collect location information.

4.1 Purpose of Location Information Collection

  • Route guidance to the conference venue (Conrad Hotel, Seoul)
  • Providing information about nearby facilities such as accommodations and restaurants
  • Providing location search services for conference-related places

4.2 How Location Information is Used

Location information is only collected when the user explicitly grants location permission, and is used solely for the purposes stated above. Location information is used only in real-time and is not stored separately.

4.3 Consent and Withdrawal of Location Information Collection

Location information collection requires explicit user consent through Android's runtime permission system. Users can withdraw location permission at any time through device settings, and basic app functions (such as viewing conference schedules) will continue to be available even after permission withdrawal.

5. Retention and Use Period of Personal Information

This app processes and retains personal information within the retention and use period of personal information as stipulated by law or within the retention and use period of personal information agreed upon when collecting personal information from the information subject.

  • Account Information: Deleted immediately upon account deletion request. However, if retention is required by relevant laws, it will be retained for the required period and then deleted.
